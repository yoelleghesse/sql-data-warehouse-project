# SQL Data Warehouse Project

This project demonstrates an end-to-end **data warehousing and analytics solution** using **SQL Server**, covering the complete pipeline from raw data ingestion to analytical reporting. It showcases data engineering, ETL processes, data modeling, and SQL-based analytics to transform raw business data into actionable insights.

---

## 🚀 Project Overview

The project is divided into two main components:

1. **Data Engineering** – Building a modern SQL Server data warehouse
2. **Data Analytics** – Generating business insights through SQL queries

---

# 🏗️ Data Engineering: Building the Data Warehouse

## Objective

Develop a modern **SQL Server data warehouse** that consolidates sales data from multiple business systems into a centralized repository for analytics and reporting.

### Requirements

* **Data Sources**

  * Import data from two source systems:

    * ERP
    * CRM
  * Source data is provided as CSV files.

* **Data Quality**

  * Clean and validate data.
  * Resolve missing, duplicate, and inconsistent records before loading.

* **Data Integration**

  * Combine ERP and CRM data into a single, analytics-friendly data model.
  * Design the warehouse to support efficient analytical queries.

* **Scope**

  * Load only the most recent dataset.
  * Historical tracking (historization/SCD) is not required.

* **Documentation**

  * Provide clear documentation of the data model and warehouse architecture for both technical and business users.

# 📊 Data Analytics & Reporting

## Objective

Develop SQL-based analytical queries to generate business insights across key domains.

### Analytics Focus

* 👥 Customer Behavior
* 📦 Product Performance
* 📈 Sales Trends

These analyses provide stakeholders with meaningful business metrics to support data-driven decision-making.
